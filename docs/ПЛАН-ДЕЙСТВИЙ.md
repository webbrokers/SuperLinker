# План действий — SuperLinker

> **Статус: утверждён — разработка MVP в процессе** (2026-06-12).

---

## 1. Суть продукта (MVP)

**SuperLinker** — простой сервис сокращения URL с аналитикой и админкой.

| Функция | Описание |
|---------|----------|
| Сокращение | Любой посетитель вставляет URL → получает короткую ссылку |
| Slug | По умолчанию случайный **6 символов**; опционально свой код |
| Статистика | График по дням, CSV переходов, IP + браузer + referer |
| Админка | Пароль, список ссылок, тестовые данные, расширенная аналитика |
| Дизайн | Современный UI по [DESIGN.md](DESIGN.md) — light/dark, bento-карточки |

## 3. Технический стек

| Компонент | Решение |
|-----------|---------|
| Backend | Python 3.11+ — **WSGI на stdlib** (`wsgiref.simple_server`) |
| HTTP-роутинг | Свой лёгкий роутер поверх WSGI (без Flask) |
| БД | **SQLite** (`sqlite3` stdlib) — файл на Volume |
| Frontend | HTML + CSS + **vanilla JS** (без фреймворков и CDN) |
| График | **Canvas API** |
| QR-код | **Canvas + свой JS-encoder** (без npm/CDN) |
| Локально | `python app.py` → `http://localhost:5000` |
| Продакшен | **Railway** → `https://*.up.railway.app` |
| Деплой | `railway.toml`, команда `python app.py`, **без gunicorn** |

**Почему без Flask:** по решению заказчика — zero pip dependencies.  
**Примечание:** для MVP на Railway `wsgiref` достаточен; при росте нагрузки можно обсудить gunicorn отдельно.

Подробности Railway: **[DEPLOY-RAILWAY.md](DEPLOY-RAILWAY.md)**

## 6. API и маршруты

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/` | Главная: форма сокращения |
| POST | `/api/shorten` | `{ url, slug?, expires_at?, utm_*? }` |
| GET | `/{slug}` | 302 редирект + запись клика |
| GET | `/health` | Health check для Railway |
| GET | `/admin/login` | Форма входа |
| POST | `/admin/login` | Проверка пароля |
| GET | `/admin` | Список ссылок (auth) |
| GET | `/admin/links/{id}` | Статистика + график + топ referer |
| GET | `/api/links/{id}/stats` | JSON: визиты по дням |
| GET | `/api/links/{id}/clicks.csv` | CSV переходов по ссылке |
| GET | `/api/admin/export-all.csv` | CSV всей статистики |
| POST | `/api/admin/generate-test-data` | Тестовые данные 30 дней |
| POST | `/api/admin/clear-test-data` | Удалить `is_test = true` |

## 12. Пояснение: «статическая витрина» (вопрос 7)

Имелась в виду **отдельная маркетинговая страница** на GitHub Pages (`username.github.io/SuperLinker`) — красивый landing «О сервисе», без backend.

**Ваш случай:** Railway уже отдаёт и главную форму, и админку по одному URL.  
**Вывод: отдельная витрина не нужна** — одна точка входа на Railway достаточна.
