# Дизайн SuperLinker — стиль и UI

> Основано на мировых трендах веб-дизайна 2025–2026.  
> **Ограничение проекта:** без внешних CDN (шрифты, иконки, CSS-фреймворки) — всё своё.

---

## 1. Тренды, которые берём в MVP

| Тренд | Как применяем в SuperLinker |
|-------|----------------------------|
| **Минимализм с акцентом** | Одна главная кнопка «Сократить», мало визуального шума |
| **Bento-карточки** | Блоки: форма, результат, статистика — отдельные «плитки» с мягкими тенями |
| **Крупная типографика** | Заголовок 2–2.5rem, короткая ссылка — моноширинный акцентный блок |
| **Мягкие скругления** | `border-radius: 12–16px` на карточках и полях ввода |
| **Глубина через тень, не neumorphism** | Лёгкая тень `0 4px 24px rgba(0,0,0,0.08)` — современный flat + depth |
| **Градиент как акцент** | Тонкий gradient на CTA-кнопке и hero-фоне (не «радуга 2018») |
| **Тёмная тема** | Переключатель light/dark — стандарт ожиданий в 2025+ |
| **Системные шрифты** | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` — быстро, без CDN |
| **Микро-анимации** | 150–200ms на hover/focus; копирование — короткий feedback «Скопировано!» |
| **Доступность (a11y)** | Контраст WCAG AA, `:focus-visible`, крупные зоны клика (min 44px) |

### Что сознательно не используем

- Glassmorphism «ради моды» — устаревает, хуже читаемость
- Перегруженные landing с 10 секциями — это MVP, не маркетинговый сайт
- Внешние icon-fonts — простые SVG inline или Unicode-символы

## 2. Цветовая палитра SuperLinker

Рабочее название стиля: **«Electric Link»** — технологичный, доверительный, не корпоративно-скучный.

### Светлая тема

| Роль | Цвет | HEX |
|------|------|-----|
| Фон страницы | Off-white | `#F8FAFC` |
| Карточка | Белый | `#FFFFFF` |
| Текст основной | Slate | `#0F172A` |
| Текст вторичный | Gray | `#64748B` |
| Акцент (кнопки, ссылки) | Electric violet | `#6366F1` |
| Акcent hover | Deep indigo | `#4F46E5` |
| Успех (скопировано) | Emerald | `#10B981` |
| Ошибка | Rose | `#F43F5E` |
| График — линия/столбцы | Indigo gradient | `#6366F1` → `#818CF8` |
| Border | Light slate | `#E2E8F0` |

### Тёмная тема

| Роль | Цвет | HEX |
|------|------|-----|
| Фон | Deep slate | `#0F172A` |
| Карточка | Slate 800 | `#1E293B` |
| Текст | Slate 50 | `#F8FAFC` |
| Акcent | Soft indigo | `#818CF8` |
| Border | Slate 700 | `#334155` |

### Hero-gradient (фон главной, subtle)

```css
/* Светлая */
background: linear-gradient(135deg, #F8FAFC 0%, #EEF2FF 50%, #F8FAFC 100%);

/* Тёмная */
background: linear-gradient(135deg, #0F172A 0%, #1E1B4B 50%, #0F172A 100%);
```

## 4. Компоненты UI (CSS-классы, план)

| Класс | Назначение |
|-------|------------|
| `.card` | Bento-карточка с padding и shadow |
| `.btn-primary` | Градиентная CTA |
| `.btn-ghost` | Вторичные действия |
| `.input` | Поле URL / slug |
| `.short-url-result` | Моноширинный блок результата |
| `.chart-wrap` | Контейнер Canvas |
| `.theme-toggle` | Переключатель темы (localStorage) |
| `.toast` | «Скопировано!» |

---

## 5. QR-код без библиотек

Генерация QR на клиенте через **минимальный JS-алгоритм** (или Canvas по таблице модулей QR) — без npm/CDN.  
Если алгоритм окажется слишком объёмным для MVP — fallback: кнопка «QR» открывает modal с QR, нарисованным упрощённым encoder (~200 строк JS, проверенный паттерн для small URLs).

---

## 6. Адаптив

- Mobile-first: форма на всю ширину на `< 640px`
- Таблица админки — горизонтальный scroll на мобиле
- График — min-height 200px, подстраивается под ширину
